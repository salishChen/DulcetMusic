# 愉乐音乐播放器：软件功能详情

> 依据 `android` 分支当前工作树代码整理，基线提交 `520e469`，整理日期 2026-09-25。本文件描述代码中已实现的行为；界面说明以当前 Kotlin/Compose 实现为准。

## 1. 产品与运行范围

愉乐是一款原生 Android 音乐播放器，既可管理设备上的音频，也可连接 Subsonic 服务器导入、播放和缓存远程音乐。应用采用 Kotlin、Jetpack Compose、Media3、SQLite 和 OkHttp；最低 Android API 24，目标 API 36。首次启动加载已有曲库和偏好，不自动扫描本机音乐，用户从“扫描音乐”页导入。

| 层级 | 职责 | 主要模块 |
| --- | --- | --- |
| 应用入口 | 初始化偏好、数据库、播放控制器、曲库及远程配置；组织导航 | `app` |
| 数据与基础能力 | 歌曲模型、SQLite、媒体扫描、Subsonic 网络、缓存、播放服务、通用组件 | `core:model/common/database/media/network/cache/player/designsystem` |
| 功能页面 | 曲库浏览、收藏、歌单、搜索、扫描、统计、远程配置、设置和播放页 | `feature:*` |

代码依据：[应用入口](../app/src/main/kotlin/com/mtechviral/musicfinderexample/YuleMusicApplication.kt)、[导航](../app/src/main/kotlin/com/mtechviral/musicfinderexample/ui/YuleMusicApp.kt)、[构建配置](../app/build.gradle.kts)。

## 2. 页面结构与通用交互

主界面侧边栏有九个一级入口：**歌曲、专辑、艺术家、歌单、喜欢、扫描音乐、远程配置、统计、设置**。搜索、专辑/艺术家/歌单详情、缓存管理、桌面歌词设置及排除列表为二级页面。底部迷你播放栏跨页面显示；点开后以覆盖层展开“正在播放”。侧边栏可由按钮或手势开合，切换一级页面时保存页面状态。清空播放队列后播放栏仍显示占位曲目“愉乐~愉悦~”。

## 3. 曲库导入与维护

### 3.1 扫描来源

| 来源 | 触发方式和处理 | 结果 |
| --- | --- | --- |
| Android 媒体库 | 点击“扫描安卓媒体库”，按系统版本申请音频读取权限；查询 MediaStore 中受支持的文件路径 | 解析音频元数据并批量入库，来源记为 `media_library` |
| 指定文件夹 | 通过系统目录选择器选目录，转换为本机路径后递归遍历；不能转换时提供绝对路径手动输入 | 解析所选目录及子目录中的音频，来源记为文件夹路径 |
| Subsonic 远程音乐 | 已配置服务器后，从远程逐级获取歌曲，按 50 首一批导入 | 歌曲入库后后台缓存远程封面 |

本地扫描按 30 首一批解析并写库，展示已处理、总数、失败数和完成汇总；入库前过滤排除列表中的歌曲/艺术家。扫描支持的扩展名为 `.mp3`、`.m4a`、`.mp4`、`.flac`、`.ogg`、`.opus`、`.wav`、`.aiff`、`.aifc`、`.ape`。可读取歌名、歌手、专辑、音轨、时长、码率、采样率、封面和部分格式的内嵌歌词等元数据。读取不到的字段允许为空，界面将艺术家/专辑回退为“未知艺术家/未知专辑”。

“清空音乐库”需二次确认；执行时停止播放、清空当前队列、删除所有歌曲记录及缓存文件。数据库外键会移除这些歌曲与歌单的关联，歌单本身仍保留。

代码依据：[扫描页](../feature/scan/src/main/kotlin/com/mtechviral/musicfinderexample/feature/scan/ScanScreen.kt)、[扫描服务](../core/media/src/main/kotlin/com/mtechviral/musicfinderexample/core/media/MetadataScanService.kt)、[格式列表](../core/media/src/main/kotlin/com/mtechviral/musicfinderexample/core/media/AudioFormats.kt)、[元数据解析](../core/media/src/main/kotlin/com/mtechviral/musicfinderexample/core/media/MetadataParser.kt)、[数据库表结构](../core/database/src/main/kotlin/com/mtechviral/musicfinderexample/core/database/MusicDatabase.kt)。

### 3.2 去重与重新扫描规则

导入时先按稳定标识匹配已有歌曲：远程歌曲按 `remoteId + 来源`（来源为按服务器区分的
`subsonic@用户名@服务器地址`，旧库 `subsonic` 来源的行在身份一致时兼容迁移），
本地歌曲按文件路径，兜底按标准化后的“歌名｜艺术家｜专辑”身份键。命中已有行时
**只更新扫描元数据**（标题、路径、时长、码率、来源等），保留喜欢、播放次数、
最后播放、歌词与音频/封面缓存等用户状态及主键（歌单绑定不受影响）；新扫描到的
内嵌歌词非空时才覆盖歌词。未命中时插入新行。远程歌曲的 `path` 为稳定定位符
`subsonic://<remoteId>@<来源哈希>`（不含认证参数），播放/下载时临时生成流地址。

代码依据：[SongDao](../core/database/src/main/kotlin/com/mtechviral/musicfinderexample/core/database/dao/SongDao.kt)、[Song 模型](../core/model/src/main/kotlin/com/mtechviral/musicfinderexample/core/model/Song.kt)。

## 4. 曲库浏览、搜索与收藏

| 页面 | 当前功能 |
| --- | --- |
| 歌曲 | 浏览全曲库；六种排序：歌名、艺术家、专辑、添加日期、播放次数、时长；再次选择同一排序项可切换升/降序。可点歌播放、随机播放、打开搜索；长按进入多选，可全选、批量加歌单、插入当前曲目后播放或永久删除。单曲提供更多操作和音质徽章（无损 `SQ` / 符合条件的高解析 `HR`）。空曲库显示扫描入口。 |
| 专辑 | 从曲库按「专辑名 + 专辑艺术家」复合键聚合专辑列表（同名不同艺术家的专辑各自独立）；进入详情看封面、艺术家、歌曲数及曲目。可播放全部、随机播放、点曲目播放，并可从菜单将曲目加到歌单。 |
| 艺术家 | 从曲库聚合艺术家列表；详情展示头像、歌曲/专辑数量、其专辑和曲目；可进入专辑、播放全部或随机播放、处理曲目。 |
| 喜欢 | **仅收藏单曲**。展示已喜欢歌曲，点歌以喜欢列表为队列播放，点红心取消喜欢；不提供专辑/艺术家收藏页签。 |

全库搜索需要输入至少 **2 个字符**，结果分歌曲、专辑和艺术家三类。歌曲匹配歌名、艺术家或专辑；专辑、艺术家分别按自身名称匹配。界面最多展示 100 条歌曲、50 个专辑、50 位艺术家。

## 5. 歌单

用户可新建和删除本地歌单，在歌单详情查看曲目，点歌时将本歌单设为播放队列；曲目菜单支持播放、加到播放队列、加到其他歌单、喜欢和“从本歌单移除”。“从本歌单移除”仅解除关联，不删除曲库中的歌曲。

远程功能有两条方向：

1. **从 Subsonic 同步到本地**：读取远程歌单；同名本地歌单复用，远程歌曲按 `remoteId` 查找或补入本地库，再将关联追加到歌单。当前同步不删除、本地重排或重命名已有歌单内容。
2. **本地歌单推送到 Subsonic**：已配置服务器时，长按本地歌单可选择创建远程歌单；仅包含远程 ID 的歌曲可用于推送。该操作创建新的远程歌单，不更新既有远程歌单。

代码依据：[歌单列表](../feature/playlists/src/main/kotlin/com/mtechviral/musicfinderexample/feature/playlists/PlaylistsScreen.kt)、[歌单详情](../feature/playlists/src/main/kotlin/com/mtechviral/musicfinderexample/feature/playlists/PlaylistDetailScreen.kt)、[远程歌单实现](../core/network/src/main/kotlin/com/mtechviral/musicfinderexample/core/network/SubsonicService.kt)、[歌单 DAO](../core/database/src/main/kotlin/com/mtechviral/musicfinderexample/core/database/dao/PlaylistDao.kt)。

## 6. 播放与正在播放页

Media3 的 `MediaSessionService` 和 ExoPlayer 承担后台播放；系统媒体按键、耳机/蓝牙控制及通知栏媒体控制经由同一会话处理。应用内可播放/暂停、上一首、下一首、拖动进度和静音。播放模式依次为**列表循环 → 随机播放 → 单曲循环**。播放队列支持整列播放、随机播放、插到当前曲目之后、移除单项及清空。队列持久化（格式 v2）同时保存当前顺序、入列原始顺序与当前条目下标：启动时原样还原队列与播放模式并定位到上次的当前条目（不自动播放），随机模式重启后切回顺序模式仍可找回入列顺序；同一首歌重复入列时按条目下标精确定位。

正在播放页包含封面/歌词区域与队列页。封面和歌词可切换；歌词按当前时间高亮并自动滚动，点歌词可跳到对应位置。页面可用手势展开/收起，提供进度、播放控制、模式、喜欢、悬浮歌词、静音及队列入口。队列清空后显示占位歌曲，不提供真实歌曲的播放操作。

本地歌曲直接用文件播放；远程歌曲优先使用已缓存音频，未缓存时使用流地址播放并可后台缓存。喜欢远程歌曲时，若“缓存我喜欢”已开启，会自动缓存音频和封面。

代码依据：[播放服务](../core/player/src/main/kotlin/com/mtechviral/musicfinderexample/core/player/PlaybackService.kt)、[播放控制器](../core/player/src/main/kotlin/com/mtechviral/musicfinderexample/core/player/PlayerController.kt)、[播放队列](../core/player/src/main/kotlin/com/mtechviral/musicfinderexample/core/player/PlaylistRepository.kt)、[播放模式](../core/model/src/main/kotlin/com/mtechviral/musicfinderexample/core/model/PlayMode.kt)、[播放覆盖层](../feature/nowplaying/src/main/kotlin/com/mtechviral/musicfinderexample/feature/nowplaying/NowPlayingOverlay.kt)、[歌词页](../feature/nowplaying/src/main/kotlin/com/mtechviral/musicfinderexample/feature/nowplaying/NowPlayingLyrics.kt)。

## 7. 歌词、通知和桌面能力

- **歌词来源**：本地扫描读取部分格式的内嵌歌词；远程曲目在已有歌词为空时，于播放后后台请求 Subsonic 歌词，成功后回写数据库与当前界面。LRC 解析提供时间定位。当前代码没有独立 `.lrc` 旁挂文件扫描流程。
- **通知栏**：媒体会话通知支持系统播放控制；自定义“词/解锁”按钮控制悬浮歌词的显示、解锁与关闭。
- **悬浮歌词**：获系统“显示在其他应用上层”权限后可显示；支持单/双行、10～36 字号、三档字重、预设颜色、拖动、锁定位置和重新居中。设置写入 `lyrics_overlay_prefs`，运行中的悬浮窗可即时刷新。
- **桌面小组件**：展示封面、歌名和播放/暂停按钮；点击组件可返回应用。

代码依据：[内嵌歌词读取](../core/media/src/main/kotlin/com/mtechviral/musicfinderexample/core/media/EmbeddedLyricsReader.kt)、[LRC 解析](../core/common/src/main/kotlin/com/mtechviral/musicfinderexample/core/common/LrcParser.kt)、[悬浮歌词管理](../core/player/src/main/kotlin/com/mtechviral/musicfinderexample/core/player/LyricsOverlayManager.kt)、[悬浮歌词服务](../core/player/src/main/kotlin/com/mtechviral/musicfinderexample/core/player/FloatingLyricsService.kt)、[桌面歌词设置](../feature/settings/src/main/kotlin/com/mtechviral/musicfinderexample/feature/settings/LyricsOverlaySettingsScreen.kt)、[小组件](../core/player/src/main/kotlin/com/mtechviral/musicfinderexample/core/player/MusicWidgetProvider.kt)。

## 8. Subsonic 连接与缓存

远程配置页可填写内网地址、公网地址、用户名、密码，并提供测试连接、保存和删除。至少填写一个地址；填写的地址需带 `http://` 或 `https://`。两种地址都存在时，连接先探测内网，再尝试公网；探测成功的地址在进程中复用。“测试连接”只做探测、**不写入配置**（失败不影响已保存的服务器），并区分地址格式错误、认证失败与网络不可达；只有“保存配置”才持久化。密码以 Android Keystore 加密形式保存在数据库中（不进备份），日志与错误消息中的认证参数（u/s/t）统一脱敏。远程服务提供歌曲、歌单、封面、歌词和流媒体地址；流地址在播放/下载时临时生成，数据库只保存稳定定位符。

缓存池默认上限 **2 GB**，设置范围 **500 MB～50 GB**。远程音频以流式下载到临时文件，完成后改名；可在缓存管理页查看已缓存歌曲与容量、多选删除音频缓存或清空全部缓存（清空同时重置音频与封面的数据库缓存字段，封面可重新下载）。容量口径包含音频、封面与临时文件；容量不足时先清理下载中断残留的 `.tmp`，再按「最近使用」时间淘汰最早的歌曲缓存，仍不足时淘汰最旧的封面缓存；播放/命中缓存会刷新最近使用时间（接近严格 LRU），删除失败时保留记录并停止淘汰。远程封面另存于缓存目录。

代码依据：[远程配置页](../feature/subsonic/src/main/kotlin/com/mtechviral/musicfinderexample/feature/subsonic/SubsonicConfigScreen.kt)、[Subsonic 客户端](../core/network/src/main/kotlin/com/mtechviral/musicfinderexample/core/network/SubsonicService.kt)、[缓存服务](../core/cache/src/main/kotlin/com/mtechviral/musicfinderexample/core/cache/CacheService.kt)、[缓存管理页](../feature/cache/src/main/kotlin/com/mtechviral/musicfinderexample/feature/cache/CacheManageScreen.kt)。

## 9. 统计与设置

统计页显示“最常播放”和“最近播放”两组列表，每组最多 50 首；可点选歌曲播放。概览卡片由全库 SQL 聚合生成：总播放次数为全部歌曲播放次数求和、已听歌曲为播放次数大于 0 的歌曲计数（不受 Top 50 列表上限影响），第三项为“近7天播放”（最近 7 天内播放过的歌曲数）。

设置页提供跟随系统/浅色/深色主题、缓存池上限、已用容量、“缓存我喜欢”开关、缓存管理、悬浮歌词开关、桌面歌词细项、排除列表及关于（版本号取自安装包，与构建 versionName 一致）。排除列表可管理单曲和艺术家；删除在线歌曲/艺术家时可记录排除项，后续扫描会跳过匹配项。

代码依据：[统计页](../feature/stats/src/main/kotlin/com/mtechviral/musicfinderexample/feature/stats/StatsScreen.kt)、[设置页](../feature/settings/src/main/kotlin/com/mtechviral/musicfinderexample/feature/settings/SettingsScreen.kt)、[排除列表页](../feature/settings/src/main/kotlin/com/mtechviral/musicfinderexample/feature/settings/ExclusionListScreen.kt)、[排除规则](../core/common/src/main/kotlin/com/mtechviral/musicfinderexample/core/common/ExclusionList.kt)。

## 10. 数据保存与权限

| 数据 | 当前保存方式 |
| --- | --- |
| 歌曲元数据、喜欢状态、播放统计、歌单及关联、艺术家元数据、Subsonic 配置 | SQLite `music_player.db`，版本 8，共五张表：`songs`、`playlists`、`playlist_songs`、`artists_meta`、`subsonic_config`。Subsonic 密码以 Android Keystore 加密（AES-GCM）存储；远程歌曲 `path` 为稳定定位符（不含认证参数）；该文件已从云备份与设备迁移中排除 |
| 主题、缓存池大小、自动缓存喜欢、上次播放队列/模式 | `yule_music_prefs`，读取时兼容旧版 `FlutterSharedPreferences` 的相应键；队列为 v2 格式（当前顺序 + 入列原始顺序 + 当前条目下标） |
| 悬浮歌词 | `lyrics_overlay_prefs` |
| 音频/封面缓存 | 应用数据目录中的 `app_flutter/subsonic_cache` |

媒体库扫描使用音频读取权限；通知和悬浮歌词分别涉及通知权限、悬浮窗权限；远程服务需要网络访问。指定文件夹扫描虽然使用系统目录选择器，但当前实现随后转换为文件路径处理，实际可读取范围依赖设备系统与存储授权。清单还声明了“所有文件访问”权限；该路径的兼容性与权限范围是待优化项。
