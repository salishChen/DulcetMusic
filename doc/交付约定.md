# 交付约定

**每次任务结束必须打包正式版（release APK）并放到桌面。**（用户 2026-09-27 约定）

执行要点：

1. 有代码变更时：
   - 按变更内容在 `CHANGELOG.md` 记录，并递增 `app/build.gradle.kts` 的
     `versionName` / `versionCode`；
   - 提交全部改动（含版本号）；
   - 构建 `.\gradlew.bat :app:assembleRelease`（JAVA_HOME=`D:\code\DevEnvironment\java\jdk-21.0.10`）；
   - 将 `app\build\outputs\apk\release\app-release.apk` 复制到桌面，
     命名 `愉乐音乐-<versionName>-release.apk`，并向用户报告交付路径。
2. 无代码变更时：告知用户当前桌面最新安装包仍为最新版本，无需重新打包。
3. 打包前确保 `:app:compileDebugKotlin` 与 `testDebugUnitTest` 通过；
   打包后可用 `apksigner verify --print-certs` 确认正式签名。
